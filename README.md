# Тихий погост — интерактивная SVG-версия

## Запуск
Откройте index.html через Live Server в VS Code, либо выполните `python -m http.server 8000` в папке и откройте http://localhost:8000. Весь проект в одном HTML: встроенные CSS, ES-модуль JavaScript и SVG, без сторонних библиотек, изображений, шрифтов и сети.

## Что изменено
Фото полностью заменено самостоятельно нарисованной SVG-схемой. Надгробия — настоящие HTML-кнопки с SVG внутри, а не метки поверх неинтерактивных могил. Нажимается вся прямоугольная область надгробия. Декорации имеют pointer-events:none. Могилы не перекрываются; карта при узком экране прокручивается горизонтально, список доступен без прокрутки карты.

## Функции
12 мест, 2 заняты исходно. Фильтры по вместимости и цене; список и карта из одного массива. Гости — целое число от 1 до вместимости, ночи — от 1 до 30. Расчёт тариф × ночи. Бронь занимает место целиком до отмены. Подтверждение вызывает падающий гробик. Занятое место нельзя забронировать: открывается диалог. Всего пять нажатий на одно место/кнопку «Постучать ещё раз» вызывают скелета и освобождают место, удаляя связанную бронь. Число стуков не сохраняется, освобождение сохраняется.

Брони сохраняются в localStorage под ключом quiet-graveyard-svg-v2. Данные предыдущей версии не импортируются: схема и идентификаторы изменены. При ошибке хранилища сайт работает в памяти и предупреждает пользователя. Сброс удаляет только ключ этой версии. Никаких платежей, регистрации и реальных услуг. Данные доступны только в текущем браузере. Нет серверной синхронизации, календаря дат или гарантии транзакций между вкладками.

## Проверка
1. Нажмите по центру, краю и основанию любого свободного надгробия: должна открыться карточка и обновиться выделение в списке.
2. Выберите место в списке: оно должно выделиться на карте.
3. Проверьте оба фильтра. «От 3 гостей» + «До 900 ₽» дают пустой результат. Если выбранное место скрыто, выбор сбрасывается.
4. Введите пустые поля, 0, дроби и ночи 31: бронь не создаётся. Превышение вместимости также показывает ошибку.
5. Подтвердите корректную бронь. Гробик падает, место занято; двойной клик не создаёт дубль. Обновите страницу.
6. Отмените бронь и забронируйте место повторно.
7. Нажмите занятую могилу и постучите ещё 4 раза: скелет выходит, место свободно, связанная бронь исчезает. Обновите страницу.
8. Проверьте Tab/Enter, Escape в диалоге, горизонтальную прокрутку на телефоне и выбор через список.
9. Включите уменьшение движения в системе — анимации отключаются.

Браузерный прогон автоматически не выполнялся. Перед сдачей проверьте сценарий выше.

## Публикация
Создайте репозиторий, загрузите index.html и README.md в корень. Settings → Pages → Deploy from a branch → основная ветка → /(root). После публикации проверьте сайт по публичной ссылке. Репозиторий и публикация автоматически не создавались.
